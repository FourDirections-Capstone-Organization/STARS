3. In-Depth Codebase Security Audit Findings (SAST & Architecture)

SEC-01: Mass Assignment Privilege Escalation in Profile Updates CRITICAL (CVSS 9.1)
Target: backend/Modules/UserAccountManagement/UserService.cs | Category: A01:2021 — Broken Access Control | CWE: CWE-269, CWE-915

Vulnerability Mechanics: UserService.UpdateAsync allowed self-profile updates (requestUserId == id) without whitelisting editable fields. A non-manager caller could supply administrative attributes (Role: "Manager", DepartmentId, AllowedSystems) to elevate their privileges to full Administrator.

Remediation & Verification: Caller role is validated; if not an authenticated Manager, privileged fields (Role, DepartmentId, JobPositionId, TargetSystems, AllowedSystems) are forcefully nullified. Verified in UserSecurityTests.cs.
SEC-02: Missing HTTP Security Headers & Missing HSTS HIGH (CVSS 7.5)
Target: backend/Middleware/SecurityHeadersMiddleware.cs & Program.cs | Category: A05:2021 — Security Misconfiguration | CWE: CWE-693, CWE-1021

Vulnerability Mechanics: Responses lacked Content-Security-Policy, X-Frame-Options: SAMEORIGIN, X-Content-Type-Options: nosniff, and Strict-Transport-Security, leaving the system susceptible to clickjacking framing and MIME confusion.

Remediation & Verification: Added custom SecurityHeadersMiddleware injecting strict CSP, anti-clickjacking, and nosniff headers. Enforced app.UseHsts() in production. Verified across all HTTP endpoints.
SEC-03: Overly Permissive CORS Policy with Credentials Allowed HIGH (CVSS 8.1)
Target: backend/Modules/Utilities/CorsPolicyHelper.cs & Program.cs | Category: A01:2021 — Broken Access Control | CWE: CWE-942

Vulnerability Mechanics: Allowed origins via .EndsWith(".vercel.app") while enabling credentials. Any attacker registering an arbitrary Vercel site could issue cross-origin requests to exfiltrate user data.

Remediation & Verification: Implemented CorsPolicyHelper.cs with an exact canonical whitelist. Suffix wildcard completely eliminated. Verified in CorsPolicyHelperTests.cs across 13 test scenarios.
SEC-04: Host Header / Origin Link Poisoning in Email Verification HIGH (CVSS 7.4)
Target: backend/Controllers/EmailVerificationController.cs | Category: A01:2021 — Broken Access Control | CWE: CWE-601, CWE-644

Vulnerability Mechanics: GetClientBaseUrl() trusted incoming Origin and Referer headers without validation, permitting attackers to generate official verification emails pointing to malicious phishing links.

Remediation & Verification: Origin header is strictly sanitized against CorsPolicyHelper.IsOriginAllowed(). Unapproved hosts fall back to canonical production frontend URL.
SEC-05: Broken Object-Level Authorization (BOLA / IDOR) on Task Attachments HIGH (CVSS 7.7)
Target: backend/Modules/TaskManagement/AttachmentService.cs & AttachmentController.cs | Category: A01:2021 — Broken Access Control | CWE: CWE-639

Vulnerability Mechanics: Attachment download endpoint accepted file GUIDs without validating caller's relationship to the task, allowing unauthorized employees to retrieve cross-department sensitive documents.

Remediation & Verification: Enforced authorization check in CanUserAccessAttachmentAsync (caller must be Manager, task creator, assigned member, or department member). Verified with unit tests returning HTTP 403 Forbidden on unauthorized access.
SEC-06: Plaintext Storage of Sensitive Tokens at Rest HIGH (CVSS 7.2)
Target: backend/Modules/Utilities/TokenHasher.cs & AuthService.cs | Category: A02:2021 — Cryptographic Failures | CWE: CWE-312, CWE-916

Vulnerability Mechanics: Refresh tokens, password reset tokens, and email verification tokens were stored in cleartext in PostgreSQL columns, exposing accounts if database backups or read replicas were compromised.

Remediation & Verification: Built TokenHasher.cs utilizing SHA-256 cryptographic hashing. Tokens are hashed prior to storage and lookups compare hashed values. Verified across authentication test suite.
SEC-07: Committed Integration API Keys in Source Control MEDIUM (CVSS 6.5)
Target: backend/appsettings.json & docker-compose.yml | Category: A02:2021 — Cryptographic Failures | CWE: CWE-798

Vulnerability Mechanics: 64-character hexadecimal API keys for FOMS integration were hardcoded in committed appsettings.json, enabling repository readers to forge cross-system requests.

Remediation & Verification: Removed keys from source code; configured environment variable bindings (FomsIntegration__InboundApiKey). Verified via M2M test script.
SEC-08: Inadequate Session Revocation on Logout & Resuscitation MEDIUM (CVSS 6.3)
Target: backend/Middleware/SessionTimeoutMiddleware.cs | Category: A07:2021 — Identification & Auth Failures | CWE: CWE-613

Vulnerability Mechanics: Subsequent requests after logout revived sessions by resetting LastActivityAt = DateTime.UtcNow.

Remediation & Verification: Updated middleware: if !user.LastActivityAt.HasValue, immediately return HTTP 401 SESSION_TERMINATED without reviving. Verified with post-logout automated test.
SEC-09: User & Account State Enumeration on Auth Endpoints MEDIUM (CVSS 5.3)
Target: backend/Modules/AuthenticationAndCredentials/AuthService.cs | Category: A07:2021 — Identification & Auth Failures | CWE: CWE-204, CWE-200

Vulnerability Mechanics: Forgot-password endpoint returned differential error messages for non-existent vs deactivated vs valid accounts.

Remediation & Verification: Standardized generic success response regardless of account existence. Verified with AntiEnumerationSecurityTests.cs.
SEC-10: File Upload Validation Relying Solely on File Extension MEDIUM (CVSS 6.8)
Target: backend/Modules/Utilities/FileSignatureValidator.cs & AttachmentService.cs | Category: A04:2021 — Insecure Design | CWE: CWE-434

Vulnerability Mechanics: Uploads were validated only by string extension, allowing executable scripts disguised as .pdf or .png to be stored.

Remediation & Verification: Built FileSignatureValidator.cs checking magic byte headers for PDF, PNG, JPEG, and Office Open XML. Extension mismatches return HTTP 400.
SEC-11: Vulnerable Frontend NPM Dependencies MEDIUM (CVSS 5.3)
Target: frontend/package.json & package-lock.json | Category: A06:2021 — Vulnerable Components | CWE: CWE-1395

Vulnerability Mechanics: Outdated dependencies had known security advisories in transitive packages.

Remediation & Verification: Upgraded dependencies via npm audit fix. npm audit reports 0 active vulnerabilities across 352 packages.
SEC-12: Diagnostic & Error Information Disclosure MEDIUM (CVSS 5.0)
Target: backend/Program.cs & EmailVerificationController.cs | Category: A05:2021 — Security Misconfiguration | CWE: CWE-209

Vulnerability Mechanics: /api/health leaked raw exception messages (ex.Message), exposing connection strings and internal server state.

Remediation & Verification: Sanitized responses to return generic status payloads; full stack traces logged server-side via ILogger.
SEC-13: Dockerfile Production Environment Misconfiguration LOW (CVSS 3.7)
Target: backend/Dockerfile | Category: A05:2021 — Security Misconfiguration | CWE: CWE-1188

Vulnerability Mechanics: Default runtime set ENV ASPNETCORE_ENVIRONMENT=Development, exposing Scalar/OpenAPI documentation in container deployments.

Remediation & Verification: Defaulted runtime image to ENV ASPNETCORE_ENVIRONMENT=Production.
SEC-14: Client-Side JWT Persistence in Browser LocalStorage LOW / INFO (CVSS 3.5)
Target: docs/rfc-cookie-based-authentication.md | Category: A02:2021 — Cryptographic Failures | CWE: CWE-922

Vulnerability Mechanics: Tokens stored in localStorage are accessible to malicious JavaScript in case of future XSS vulnerabilities.

Remediation & Verification: Published Architectural RFC specifying complete migration to HttpOnly, Secure cookies with double-submit CSRF.
