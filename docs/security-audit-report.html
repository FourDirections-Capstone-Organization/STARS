3. Actionable Capstone Penetration Findings (SEC-15 through SEC-21)

SEC-15: Broken Object-Level Authorization (BOLA / IDOR) on Task Comment Attachments
HIGH (CVSS 7.5) ACTIONABLE
OWASP: A01:2021 — Broken Access Control | OWASP API: API1:2023 | CWE: CWE-639 | Target: TaskCommentController.cs

Mechanics: While AttachmentController was hardened under SEC-05, TaskCommentController.DownloadAttachment and DownloadLegacyAttachment retrieve files directly by GUID without validating caller permissions relative to the parent task. Any authenticated employee from Department A can download confidential billing attachments attached to comments of tasks in Department B.

Remediation Specification: Enforce task-level authorization in TaskCommentController: confirm caller is a Manager, the task creator, an assigned employee, or a member of the assigned department prior to returning file streams.
SEC-16: Unrestricted / MIME-Confusion File Upload in Task Comment Attachments
HIGH (CVSS 7.1) ACTIONABLE
OWASP: A04:2021 — Insecure Design | CWE: CWE-434 | Target: TaskCommentService.cs (lines 64–73)

Mechanics: TaskCommentService.CreateAsync verifies attachments using string file extension inspection only. It omits binary magic byte verification (FileSignatureValidator.HasValidMagicBytes), permitting disguised executable binaries or malicious HTML polyglots renamed as .pdf or .png to be uploaded and stored.

Remediation Specification: Integrate FileSignatureValidator.HasValidMagicBytes(file) into comment attachment processing, matching the hardening in AttachmentService and AnnouncementService.
SEC-17: Missing Session & Token Revocation on Password Reset and Password Change
HIGH (CVSS 7.4) ACTIONABLE
OWASP: A07:2021 — Identification & Auth Failures | CWE: CWE-613 | Target: AuthService.cs (lines 208, 291)

Mechanics: When an employee changes their password or completes an account recovery reset, user.PasswordHash is updated, but user.RefreshToken, user.RefreshTokenExpiry, and user.LastActivityAt are not cleared. An attacker who compromised tokens can continue refreshing sessions indefinitely via POST /api/auth/refresh.

Remediation Specification: In ChangePasswordAsync and ResetPasswordAsync, explicitly revoke active sessions by nullifying RefreshToken, RefreshTokenExpiry, and LastActivityAt.
SEC-18: Plaintext Password Leakage in Application Log Streams
MEDIUM (CVSS 6.2) ACTIONABLE
OWASP: A09:2021 — Security Logging Failures | CWE: CWE-532 | Target: UserService.cs (lines 907, 965)

Mechanics: In SeedDefaultManagerAsync and SeedTestAccountsAsync, user passwords are formatted directly into structured log statements (_logger.LogInformation("... with password: {Password}", ...)). Application logs exported to stdout, Docker, or Azure App Service Log Stream persist credentials in plaintext.

Remediation Specification: Redact passwords from logging statements: replace with [REDACTED_TEMP_PASSWORD].
SEC-19: Missing Rate Limiting on Email Verification & Activation Endpoints
MEDIUM (CVSS 5.3) ACTIONABLE
OWASP: A04:2021 — Insecure Design | OWASP API: API4:2023 | CWE: CWE-770 | Target: EmailVerificationController.cs

Mechanics: POST /api/email-verification/resend and /verify allow anonymous access but lack rate limiting attributes. An attacker can flood verification endpoints, saturating SMTP queues, triggering mail relay quota exhaustion, and causing denial of service.

Remediation Specification: Decorate EmailVerificationController with [EnableRateLimiting("AuthRateLimit")] (30 req/min sliding window).
SEC-20: Active Session Persistence on Administrative Account Deactivation
MEDIUM (CVSS 4.8) ACTIONABLE
OWASP: A07:2021 — Identification & Auth Failures | CWE: CWE-613 | Target: UserService.cs (line 610)

Mechanics: Deactivating an account sets user.IsDeactivated = true; user.IsActive = false; but retains active refresh tokens in the database. Defense-in-depth demands immediate token clearing upon deactivation.

Remediation Specification: In DeactivateAsync, set user.RefreshToken = null; user.RefreshTokenExpiry = null; user.LastActivityAt = null;.
SEC-21: Incomplete Modern Browser Sandboxing Headers
LOW (CVSS 3.7) ACTIONABLE
OWASP: A05:2021 — Security Misconfiguration | CWE: CWE-693 | Target: SecurityHeadersMiddleware.cs

Mechanics: SecurityHeadersMiddleware omits X-Permitted-Cross-Domain-Policies: none and Cross-Origin-Opener-Policy: same-origin.

Remediation Specification: Add X-Permitted-Cross-Domain-Policies and Cross-Origin-Opener-Policy to response headers.
